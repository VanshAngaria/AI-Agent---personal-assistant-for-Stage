# Impact report

All numbers below are generated by `python -m oua impact` from this run's state; none are typed by hand.

## Method

* **Unit:** every viewer who sent at least one trigger in the replay. Arms come from `replay/arms.csv` (randomized before the replay; the agent never chooses who is treated).
* **Same treatment of both arms:** the agent runs the identical pipeline for holdout viewers and commits the same *shadow goal* it would have pursued, then publishes nothing. Both arms are judged by the same judge, with the same rule versions, on the same simulator output.
* **Primary metric (intent-to-treat):** success of each viewer's *first* committed goal, comparing everyone in the agent arm with everyone in the holdout arm, whether or not the agent ended up publishing anything. Inconclusive goals count as not succeeded in both arms.
* **Attribution:** a signal counts only if it was received inside the goal window and, after correcting for device buffering, happened after the goal started.

## Why simpler comparisons mislead

* **Served vs everyone else** (the pilot report's method): 14.1% vs 11.5%, +2.6 pts (95% CI -0.8 to +6.0; p=0.133).
* **Served vs unserved inside the agent arm:** 14.1% vs 0.0%, +14.1 pts (95% CI +11.6 to +16.7; p=0.006).

Being *served* is not random. The agent only publishes for viewers who are in the app right now (not a buffered open), whose app is set to a dialect with content, who have an eligible goal and pass every check. Those conditions select viewers who are already more engaged. Comparing them with everyone else measures that selection, not the agent. Only the randomized arms (above) are comparable; the balance table shows they looked alike before the agent acted.

## The pilot report, recomputed

* Report headline (served vs all others): 87/217 vs 649/3674: +22.4 pts (95% CI +15.8 to +29.1; p=0.000).
* Same pilot file, randomized arms (treatment vs holdout): 349/1912 vs 387/1979: -1.3 pts (95% CI -3.8 to +1.2; p=0.300).

The 2.3x 'uplift' disappears under the randomized comparison; the pilot did not show that agent v0 helped. The report also assigned goals by subscription status at first visit only and compared against viewers who were never eligible to be served.

## Caveats

* One replay day and one simulator seed. Evaluators' seeds will move every number above.
* The simulator models a modest page effect; a null or small effect is a legitimate result and is reported as such.
* Goals with windows longer than the observed period are inconclusive, not failed.
